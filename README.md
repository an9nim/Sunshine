# Sunshine
Децентрализованный мессенджер для Android, работающий без интернета.

Sunshine использует mesh-сеть поверх Wi-Fi Direct и Bluetooth LE. Сообщения передаются от устройства к устройству, пока не достигнут адресата, никаких серверов, вышек и Wi-Fi роутеров не требуется. Всё шифруется end-to-end, история хранится только на вашем телефоне.
Чем больше устройств рядом — тем стабильнее сеть.** Каждый телефон выступает и клиентом, и роутером.
## 🔐 Безопасность и приватность

- **End-to-End шифрование**: X25519 (ECDH) + HKDF-SHA256 + AES-256-GCM.
- **Ключи не покидают устройство**: приватный ключ запечатан в Android Keystore.
- **Нет серверов**: история сообщений хранится только в локальной базе Room.
- **Регистрация по нику**: без email, телефона и паролей.

## ⚠️ Ограничения MVP

Это ранняя версия. Некоторые вещи намеренно упрощены:

- **TOFU (Trust On First Use)**: при первом контакте публичный ключ принимается без верификации. Рекомендуется сверять отпечатки вручную.
- **Нет Forward Secrecy**: используется статический ECDH. Компрометация ключа раскроет прошлые сообщения.
- **Нет подписей отправителя**: любой узел может выдать себя за другого.
- **Метаданные не защищены**: видно, кто, кому и когда отправляет сообщения.
- **Store-and-Forward только для своих**: чужие пакеты не складируются (это граница MVP).

- Проект использует Gradle Kotlin DSL. Для сборки потребуется JDK 17 и Android SDK.
